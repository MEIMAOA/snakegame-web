系统要求

SnakeGame · Windows

  • Windows 10 版本 1809 或更高 / Windows 11
  • 64 位或 32 位处理器，支持 SSE2
  • 显卡支持 DirectX 11
  • 约 200 MB 可用磁盘空间

SnakeGame · Android

  • Android 8.0（API 26）或更高
  • arm64-v8a 设备
  • 约 120 MB 可用存储空间
  • 横屏游玩，支持触屏操作

SnakeLauncherWPF

  • Windows 10 / 11（x64、x86 或 ARM64）
  • .NET 10 桌面运行时
  • 可访问 GitHub 的网络（用于检查与下载版本）
  • 约 50 MB 可用磁盘空间
